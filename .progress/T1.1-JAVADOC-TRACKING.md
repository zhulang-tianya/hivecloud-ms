## 🔧 修复标准

### 类注释模板

```java
/**
 * [类名]
 * [功能描述：负责什么功能]
 * [实现接口：XXX（如果有）]
 * [依赖组件：XXX（如果有）]
 *
 * @author HiveCloud Team
 * @date 2026-04-25
 * @see [关联类 1]
 * @see [关联类 2]
 */
```

### 字段注释模板

```java
/**
 * [字段用途说明]
 */
private FieldType fieldName;
```

### 方法注释模板

```java
/**
 * [方法功能描述]
 * [业务场景说明（如果有）]
 *
 * @param [参数名] [参数说明]
 * @return [返回值说明]
 * @throws [异常类型] [异常说明]
 */
@Override
public ReturnType methodName(ParamType param) {
    // ...
}
```

## ⚠️ 注意事项

### 必须遵守的规范

1. ✅ 所有公共类、接口必须有完整 Javadoc
2. ✅ 所有公共方法必须有@param、@return、@throws
3. ✅ 字段必须有注释说明用途
4. ✅ 常量必须有注释说明格式和用途
5. ✅ 使用@see 引用关联类
6. ✅ 使用@Override 标注重写方法

### 禁止行为

1. ❌ 禁止使用无语义命名
2. ❌ 禁止注释与代码逻辑不一致
3. ❌ 禁止缺少@param 或@return
4. ❌ 禁止使用拼音或中英混合
5. ❌ 禁止使用过期注释
