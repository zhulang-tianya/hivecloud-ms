## 四、测试编写规范

### 4.1 测试类命名

```java
// 格式：{被测试类名}Test.java
RedisServiceRegistryTest.java
DefaultHeartbeatPusherTest.java
```

### 4.2 测试方法命名

```java
// 格式：test{方法名}_{场景}.java
@Test
@DisplayName("测试服务注册 - 成功")
void testRegister_Success() { ... }

@Test
@DisplayName("测试服务注销 - 集合不为空时不删除全局服务")
void testDeregister_WhenSetNotEmpty() { ... }
```

### 4.3 测试结构（AAA 模式）

```java
@Test
@DisplayName("测试更新服务状态 - 成功")
void testUpdateStatus_Success() {
    // Given（准备）
    String serviceId = "test-service";
    ServiceInstance existingInstance = createTestInstance(serviceId, "instance-001");
    when(valueOps.get(anyString())).thenReturn(existingInstance);

    // When（执行）
    registry.updateStatus(serviceId, instanceId, ServiceStatus.DOWN);

    // Then（验证）
    verify(valueOps).set(anyString(), any(ServiceInstance.class));
    assertEquals(ServiceStatus.DOWN, existingInstance.getStatus());
}
```

### 4.4 使用的测试框架

- **JUnit 5**: 测试框架
- **Mockito**: Mock 框架
- **AssertJ**: 流式断言（可选）
- **Spring Test**: Spring 集成测试

### 7.1 运行所有测试

```bash

```

```bash

```

