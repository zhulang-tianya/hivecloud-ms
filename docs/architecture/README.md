### 3. 架构设计原则

#### 3.1 核心原则

1. **轻量优先**: 能简单不复杂，能轻量不重量
2. **去中心化**: 服务治理嵌入每个节点，无单点依赖
3. **故障域隔离**: 高并发业务独立部署，互不影响
4. **水平扩展**: 支持按需扩容，自动纳入负载均衡
5. **自愈自治**: 心跳检测、故障剔除、优雅下线

#### 3.2 技术选型

| 层次 | 技术栈 | 选型理由 |
|------|--------|----------|
| **网关层** | Spring Cloud Gateway | 高性能、响应式、易扩展 |
| **服务治理** | 自研轻量框架 | 去中心化、无侵入、可插拔 |
| **业务服务** | Spring Boot 3.x | 生态成熟、开发效率高 |
| **数据存储** | MySQL + Redis | 经典组合、稳定可靠 |
| **本地缓存** | Caffeine | 高性能、支持 TTL、统计功能 |
| **配置中心** | Nacos | 动态配置、热更新、服务发现 |
