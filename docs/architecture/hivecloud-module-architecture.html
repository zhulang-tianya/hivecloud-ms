📋 模块详细说明

🚪 hivecloud-gateway

  • 职责: 统一业务网关，所有请求的入口
  • 核心功能: 路由转发、JWT 认证、限流、日志
  • 依赖: hivecloud-starter-nacos, hivecloud-plugin-log
  • 部署优先级: P0 - 必须部署
  • 端口: 8080

👤 hivecloud-module-system

  • 职责: 系统管理核心服务
  • 核心功能: 用户管理、角色权限、菜单管理
  • 依赖: hivecloud-starter-nacos, MySQL, Redis
  • 部署优先级: P0 - 必须部署
  • 数据库: hivecloud_system

💳 hivecloud-module-payment

  • 职责: 支付服务
  • 核心功能: 微信支付、支付宝、银联支付
  • 依赖: hivecloud-starter-nacos, MySQL
  • 部署优先级: P1 - 重要服务
  • 外部调用: 微信/支付宝/银联 API

📝 hivecloud-module-claim

  • 职责: 理赔服务
  • 核心功能: 理赔申请、审核、赔付
  • 依赖: hivecloud-starter-nacos, MySQL
  • 部署优先级: P1 - 重要服务

🎁 hivecloud-module-activity

  • 职责: 活动营销服务
  • 核心功能: 优惠券、活动管理
  • 依赖: hivecloud-starter-nacos, MySQL, Redis
  • 部署优先级: P2 - 可选服务

📱 hivecloud-module-notify

  • 职责: 通知服务
  • 核心功能: 短信发送、消息推送
  • 依赖: hivecloud-starter-nacos
  • 部署优先级: P2 - 可选服务
  • 外部调用: 短信服务商 API

⚙️ hivecloud-framework

  • 职责: 核心框架层
  • 子模块:
    • starter-nacos: Nacos 统一启动器
    • plugin-engine: 插件引擎
    • heartbeat: 心跳检测
    • fault-removal: 故障摘除
    • gossip-sync: Gossip 同步
    • event-bus: 事件总线
  • 部署方式: 作为依赖被业务模块引用

🔧 hivecloud-common

  • 职责: 公共工具类层
  • 子模块:
    • common-core: 核心工具类
    • common-web: Web 通用
    • common-security: 安全认证
    • common-redis: Redis 工具
    • common-mybatis: MyBatis 配置
    • common-test: 测试工具
  • 部署方式: 作为依赖被所有模块引用

🔌 hivecloud-plugins

  • 职责: 插件化扩展
  • 核心插件:
    • plugin-auth: 认证插件
    • plugin-log: 日志插件
    • plugin-cache: 缓存插件
    • plugin-crypto: 加密插件
    • plugin-ai: AI 能力插件
    • plugin-file: 文件上传插件
  • 部署方式: 作为依赖被业务模块按需引用

☁️ Nacos 配置中心

  • 地址: 172.10.6.194:8848
  • 职责: 统一配置管理 + 服务注册发现
  • Namespace 隔离:
    • dev: 开发环境
    • test: 测试环境
    • prod: 生产环境
  • 配置方式: 父 pom.xml 统一配置

🚀 部署说明

必选部署服务 (P0)

  1. hivecloud-gateway - 业务网关
    • 所有业务请求的统一入口
    • 负责路由转发、认证鉴权、限流等
    • 启动命令：mvn spring-boot:run -pl hivecloud-gateway
  2. hivecloud-module-system - 系统管理服务
    • 提供用户、角色、权限等基础管理功能
    • 其他业务模块的基础依赖
    • 启动命令：mvn spring-boot:run -pl hivecloud-modules/hivecloud-module-system

可选部署服务 (按业务需求)

服务 优先级 业务场景 依赖
Payment (支付) P1 需要支付功能 微信/支付宝账号
Claim (理赔) P1 保险理赔业务 无
Activity (活动) P2 营销活动 无
Notify (通知) P2 短信通知 短信服务商

部署模式选择

🚀 开发环境

只部署 Gateway + System 模块

mvn spring-boot:run -Pdev

🧪 测试环境

部署所有 P0 + P1 服务

mvn spring-boot:run -Ptest

🌐 生产环境

根据业务需求部署所有服务

mvn spring-boot:run -Pprod
