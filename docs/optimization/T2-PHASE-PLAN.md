## 📋 执行摘要

T2 阶段聚焦于**业务能力增强**，在 T1 阶段完成核心底座和 P0 问题修复的基础上，实现文件管理、定时任务、在线文档、域内直连、双轨链路、事件总线等核心功能。

**核心目标**：
- ✅ 文件插件：支持本地存储、阿里云 OSS、腾讯云 COS、MinIO
- ✅ 定时任务插件：支持 cron 表达式、任务监控、失败重试
- ✅ 在线文档插件：Knife4j 集成、API 文档自动生成
- ✅ 域内直连通道：OkHttp 连接池、绕开网关高频调用
- ✅ 双轨业务链路：@FastTrack（只读）+ @StableTrack（写事务）
- ✅ 事件总线：发布订阅模式、服务间异步通信

## 🎯 任务清单

### T2.1 文件插件开发（5 天）

**任务描述**：
实现统一的文件存储插件，支持多种存储方式，提供文件上传、下载、删除、预览等功能。

**技术方案**：
- 本地存储：FileSystemStorageService
- 阿里云 OSS：OssStorageService
- 腾讯云 COS：CosStorageService
- MinIO：MinioStorageService
- 统一接口：StorageService

**交付物**：
- hivecloud-plugin-file 模块
- 存储策略接口 +4 种实现
- 文件管理 Controller + Service
- 单元测试（覆盖率>=85%）

**技术规范**：
- ✅ 遵循阿里 Java 开发手册
- ✅ 完整 Javadoc 注释
- ✅ 统一异常处理
- ✅ 文件类型校验 + 大小限制

### T2.2 定时任务插件开发（5 天）

**任务描述**：
实现轻量级定时任务调度插件，支持 cron 表达式、任务监控、失败告警等功能。

**技术方案**：
- 调度核心：ThreadPoolTaskScheduler
- cron 表达式：Spring CronExpression
- 任务持久化：MySQL + Redis
- 任务监控：JMX + 自定义指标

**交付物**：
- hivecloud-plugin-job 模块
- 任务调度核心引擎
- 任务管理 CRUD 接口
- 任务监控面板

**技术规范**：
- ✅ 任务执行日志完整记录
- ✅ 失败任务自动重试（最多 3 次）
- ✅ 支持手动暂停/恢复任务
- ✅ 任务执行时间监控

### T2.3 在线文档插件开发（3 天）

**任务描述**：
集成 Knife4j 实现 API 文档自动生成，支持文档聚合、在线调试、接口测试。

**技术方案**：
- 文档框架：Knife4j + SpringDoc
- 注解规范：OpenAPI 3.0 + Swagger 注解
- 文档聚合：多服务文档聚合
- 鉴权集成：JWT Token 自动填充

**交付物**：
- hivecloud-plugin-doc 模块
- Knife4j 自动配置类
- Swagger 注解规范文档
- 文档聚合页面

**技术规范**：
- ✅ 所有 Controller 接口有完整 Swagger 注解
- ✅ 所有 DTO/VO 有 Schema 描述
- ✅ 接口示例参数完整
- ✅ 支持在线调试

### T2.4 域内直连通道开发（4 天）

**任务描述**：
实现服务间 HTTP 直连通道，绕开网关，适用于内网高频调用场景。

**技术方案**：
- HTTP 客户端：OkHttp 连接池
- 服务发现：RedisServiceRegistry
- 负载均衡：轮询 + 权重
- 超时重试：配置化策略

**交付物**：
- hivecloud-direct-connector 模块
- OkHttp 连接池配置
- 直连调用客户端
- 负载均衡器

**技术规范**：
- ✅ 连接池参数可配置
- ✅ 超时时间可配置（默认 3s）
- ✅ 重试策略可配置（最多 2 次）
- ✅ 服务故障自动剔除

### T2.5 双轨业务链路开发（5 天）

**任务描述**：
实现快轨（只读）和稳轨（写事务）分离的业务链路，优化不同场景性能。

**技术方案**：
- 注解定义：@FastTrack / @StableTrack
- AOP 拦截器：链路识别 + 路由
- 数据源路由：读库/写库分离
- 缓存策略：快轨优先缓存

**交付物**：
- hivecloud-business-link 模块
- 双轨注解定义
- AOP 拦截器实现
- 数据源路由配置

**技术规范**：
- ✅ 快轨响应时间 <15ms
- ✅ 稳轨响应时间 <200ms
- ✅ 自动识别读写操作
- ✅ 支持手动指定链路

### T2.6 事件总线开发（4 天）

**任务描述**：
实现服务间异步通信的事件总线，支持发布订阅模式、事件持久化、重试机制。

**技术方案**：
- 事件总线：ApplicationEventMulticaster
- 事件存储：Redis Stream
- 异步处理：@EventListener + 线程池
- 重试机制：失败事件自动重试

**交付物**：
- hivecloud-event-bus 模块
- 事件总线核心实现
- 事件发布/订阅接口
- 事件监控面板

**技术规范**：
- ✅ 事件发布异步处理
- ✅ 事件失败自动重试（最多 3 次）
- ✅ 支持事件过滤
- ✅ 事件处理耗时监控

### T2.7 混合部署切换机制（3 天）

**任务描述**：
实现模块化单体与独立微服务之间的自由切换机制。

**技术方案**：
- 配置开关：application.yml 配置
- 条件加载：@ConditionalOnProperty
- 服务注册：自动识别部署模式
- 路由适配：网关/直连自动切换

**交付物**：
- 部署模式配置类
- 条件加载注解
- 服务注册适配器
- 切换机制文档

### T2.8 集成测试（5 天）

**任务描述**：
对 T2 阶段所有功能进行集成测试，确保功能正常、性能达标。

**测试范围**：
- 文件插件：上传/下载/删除
- 定时任务：调度/监控/重试
- 在线文档：文档生成/在线调试
- 域内直连：HTTP 调用/负载均衡
- 双轨链路：读写分离/性能测试
- 事件总线：发布订阅/异步处理

**交付物**：
- 集成测试用例（>=50 个）
- 性能基准测试报告
- Bug 修复清单
- 测试覆盖率报告
