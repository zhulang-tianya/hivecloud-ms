## 📊 项目概览

HiveCloud 是一个基于 Spring Cloud 构建的企业级微服务架构，采用 DDD（领域驱动设计）理念，提供完整的微服务解决方案。项目历经 T1-T4 四个阶段的开发，已达成生产就绪状态。

## 🎯 核心功能

### 服务治理

1. **服务注册与发现**
   - 基于 Redis 的中心化存储
   - Gossip 协议去中心化同步
   - 支持动态扩缩容

2. **分布式心跳探测**
   - 可配置心跳间隔
   - 多节点并发探测
   - 实时健康状态更新

3. **故障自动剔除**
   - 连续失败自动剔除
   - 超时自动剔除
   - 健康检查自动剔除

### 业务模块

1. **支付服务**
   - 支付宝支付
   - 微信支付
   - 银联支付
   - 统一接口设计

2. **理赔服务**
   - 理赔申请创建
   - 审核流程
   - 理赔打款
   - 状态跟踪

3. **活动服务**
   - 优惠券管理
   - 活动创建
   - 用户领取
   - 使用统计

4. **通知服务**
   - 短信通知
   - 邮件通知
   - 推送通知
   - 模板管理

### 插件系统

1. **AI 智能客服**
   - 智能问答
   - 风险评估
   - 自动回复

2. **数据加密**
   - AES 加密/解密
   - MD5 加密
   - SHA256 加密

3. **缓存插件**
   - 两级缓存（Caffeine + Redis）
   - 缓存穿透/雪崩防护
   - 自动过期

1. **混合服务注册机制**

   - 支持大规模集群

2. **分布式心跳探测**
   - 多节点并发探测

   - 自动剔除机制

3. **两级缓存架构**
